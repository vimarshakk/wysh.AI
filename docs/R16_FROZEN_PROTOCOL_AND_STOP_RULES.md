# R16E frozen protocol, analysis, monitoring, and stop rules

Study execution requires a version-locked protocol and statistical analysis
plan containing intended use, endpoints, sample-size method, inclusion and
exclusion criteria, split strategy, leakage controls, missing-data handling,
subgroup analysis, calibration, uncertainty, external validation, and reporting
rules. The model, prompt, clinical rules, terminology versions, and evaluation
code must be content-addressed and frozen before unblinding.

Monitoring must define schema failures, unsupported claims, evidence-grounding
failures, abstention rates, latency/resource failures, distribution shift,
subgroup disparity, and security incidents. Stop or pause conditions must be
prespecified and include material safety signal, reference-standard failure,
rights/consent uncertainty, unacceptable privacy event, or unresolvable data
integrity defect.

The current repository has no approved study protocol or real-data monitoring
run.
