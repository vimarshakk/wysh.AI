# wysh.AI observability contract

The local `/metrics` endpoint exposes low-cardinality operational telemetry for
the synthetic development lane. It is intentionally not a clinical record and
never includes prompts, FHIR payloads, evidence text, tokens, secrets, patient
identifiers, or provider response bodies.

Provider route telemetry is recorded only for the bounded provider set:

- `gemini`
- `medgemma`
- `openai-compatible`
- `vllm`
- `llama.cpp`

For each route attempt, the service records success/failure, latency buckets,
latency count, latency sum, and adapter retry count. Provider failures remain classified in the
HTTP response and audit flow without copying provider error bodies. The
gateway records the final bounded route attempt after its adapter-level retry
policy completes; this prevents retries from being mistaken for separate
clinical decisions.

The metrics endpoint is useful for local engineering and synthetic evaluation
only. It does not establish availability, safety, clinical effectiveness, an
SLO, or production readiness. Production inference remains disabled by policy.

The reproducible sanitized route evidence is generated by
`apps/api/scripts/run_routing_trace_gate.py` and written to
`artifacts/r1-test-evidence/routing-trace-gate.json`. Its synthetic scenario
forces a local MedGemma route failure followed by a local OpenAI-compatible
success, proving that route selection is observable without recording the
request or response content.

The same bounded route list is returned in `DecisionResponse.telemetry` for
successful model-backed decisions and in the orchestration model telemetry.
Policy abstentions return an empty route list. A failed gateway carries the
same trace internally for sanitized error/evidence handling; it never exposes
the original prompt or provider response body.

Provider failures also emit a redacted `decision.provider_failed` audit event
with the correlation ID, policy version, and request hash. The event contains
no provider error body or request content, allowing failure-rate analysis
without turning logs into a clinical data store.
