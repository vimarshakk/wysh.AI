# R15 intended use and claims register

## Current permitted use

wysh.AI is permitted only as an isolated engineering and research-readiness
system operating on synthetic data. It can produce draft, evidence-linked
summaries for qualified reviewers in a test environment.

## Explicitly unsupported claims

The current evidence does not support claims of diagnosis, prognosis,
treatment selection, medication or dose advice, emergency triage, autonomous
action, clinical effectiveness, or generalizability to real patients.

## Intended-use definition required before a study

Any future validation must specify the user role, care setting, target
population, inclusion/exclusion criteria, input data, output, decision point,
prediction or monitoring horizon, reference standard, human oversight, and
prohibited uses for each disease workflow and model version.

The intended-use statement must be approved by qualified clinical and
governance reviewers before study data are accessed. R15 does not approve a
study or authorize clinical use.
