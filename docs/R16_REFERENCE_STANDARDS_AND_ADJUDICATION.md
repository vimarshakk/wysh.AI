# R16C clinical reference standards and adjudication

Each intended use requires a reference standard defined before evaluation. The
standard must specify the clinical question, eligible evidence, observation
window, outcome definition, acceptable disagreement, adjudicator qualification,
blinding, and missing/indeterminate handling.

For imaging, the modality, acquisition quality, annotation schema, reader
qualification, multi-reader agreement method, and adjudication process must be
prespecified. For disease workflows, clinician-approved labels must be distinct
from model-generated explanations and deterministic monitoring rules.

No clinical labels or reference standard have been approved in this repository.
