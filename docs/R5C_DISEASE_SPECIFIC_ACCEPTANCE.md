# R5C — Disease-specific clinical intelligence engineering

Status: **ENGINEERING PASS / CLINICAL VALIDATION NO-GO / PRODUCTION NO-GO**

The R5C engine upgrades all 20 WDI conditions from generic completeness packs
to versioned disease-specific observation contracts. Each pack defines required
observations, supported units, condition-specific limitations, longitudinal
trend output, evidence references, and fail-closed behavior.

The endpoint is:

`POST /v1/disease-intelligence/disease-specific`

The response is explicitly marked `DATA_QUALITY_ONLY`, `synthetic_only`, and
`clinical_use_authorized: false`. Draft actions and clinical interpretation are
not generated by this endpoint.

Examples of descriptive derived metrics include HbA1c-to-eAG, BMI, non-HDL,
ALT/AST ratio, and growth velocity. Each has a formula, evidence references,
and a limitation statement. No threshold-based disease classification or
treatment recommendation is implemented.

Evidence: `artifacts/r5-test-evidence/r5c-pack-gate.json`.

This milestone demonstrates 20/20 disease-specific engineering workflows. It
does not establish clinical accuracy, validated prediction, or production
readiness.
