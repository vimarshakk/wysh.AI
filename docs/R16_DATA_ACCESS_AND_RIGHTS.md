# R16B dataset access and rights controls

No non-synthetic dataset is connected to wysh.AI under R16.

Before access, the owner must record the data controller/custodian, lawful
basis, permitted research purpose, data-use agreement, provenance, license,
retention/deletion period, geography, access roles, encryption, audit logging,
de-identification or pseudonymization assessment, incident response, and
cross-border processing position.

The dataset manifest must be immutable before model evaluation and must include
patient-level and temporal split identifiers without exposing patient data in
test evidence. Rights to labels, images, annotations, and derived features
must be separately confirmed.
